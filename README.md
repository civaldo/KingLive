# King Live

Projeto inicial Android para jogo de batalha interativo em lives.

## Gerar APK

Abra **Actions** e execute o workflow `Construir APK King Live`. Baixe o artefato `KingLive-debug-apk` ao finalizar.

Nesta primeira versão, comentários e presentes são simulados. A conexão real com TikTok LIVE ainda precisa de integração compatível.
