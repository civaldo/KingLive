# King Live

Aplicativo Android de batalha para lives, com equipes Leões 🦁 e Dragões 🐉.

## Versão atual

- Interface de batalha redesenhada com placar, barras de progresso e cores por equipe.
- Botões de demonstração para comentários (+1) e presentes (+5).
- Indicador claro de que a conexão real com TikTok LIVE ainda não está ativa.
- A integração real depende de um serviço compatível de recepção de eventos.

## Gerar APK pelo celular

1. Abra a aba **Actions** deste repositório.
2. Selecione **Construir APK King Live**.
3. Abra a execução mais recente e aguarde ficar verde (**Success**).
4. Entre em **Artifacts** e baixe **KingLive-debug-apk**.
5. Extraia o ZIP baixado para encontrar `app-debug.apk`.

## Integração TikTok LIVE

Leia [docs/INTEGRACAO_TIKTOK_LIVE.md](docs/INTEGRACAO_TIKTOK_LIVE.md) antes de configurar uma ponte de eventos. Os botões atuais são apenas simulações; não são prova de conexão real.
